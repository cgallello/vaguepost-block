Privacy policy

Last updated: September 9, 2026

VagueBlock is a Chrome extension that helps users identify vague quote-posts on x.com, track local strike counts, and optionally block qualifying accounts.

Information processed

When enabled on x.com, VagueBlock reads visible quote-post text, post identifiers, account handles, and visible follow-state information. It stores extension settings, the allowlist, strike counts, bounded processed-post identifiers, classifier results by post identifier, and local activity metadata.

How it is used

This information is used only on the device to identify likely vague quote-posts, prevent duplicate strikes, apply settings, and show the local activity log. On supported Chrome devices, classification uses Chrome's on-device Gemini Nano model.

No transmission or sale

VagueBlock does not send tweet content, account handles, activity records, browser history, or credentials to the developer or third parties. It does not use analytics, advertising, tracking pixels, remote model APIs, or data brokers.

Retention and control

Extension data remains in Chrome extension storage until the user deletes it, exports it, resets VagueBlock, or removes the extension. The Settings page provides export and deletion controls.

Permissions

VagueBlock requests storage and offscreen-document permissions, and access only to https://x.com/*. It does not request passwords, payment information, downloads, browsing history, or private X APIs.
