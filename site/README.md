# VagueBlock public pages

This directory is a dependency-free static site intended for GitHub Pages (or another HTTPS static host). Publish it before Chrome Web Store submission, then use the resulting `privacy.html` URL in the Store Privacy tab and `support.html` URL in the Store listing.

Before publishing:

- Add a maintained support contact to both pages.
- Confirm the privacy text matches the shipped manifest and storage behavior.
- Keep the Store listing and these pages consistent when the extension version changes.
