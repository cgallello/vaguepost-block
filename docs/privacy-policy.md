# VagueBlock privacy policy (draft)

**Last updated:** September 9, 2026

VagueBlock is a Chrome extension that helps users identify vague quote-posts on x.com, track local strike counts, and optionally block qualifying accounts.

## Information processed

To provide the feature, VagueBlock reads visible content from x.com pages where it is enabled. This may include quote-post text, post identifiers, account handles, and visible follow-state information. VagueBlock also stores the user's extension settings, allowlist, strike counts, bounded processed-post identifiers, and local activity metadata.

## How information is used

This information is used only on the device to identify likely vague quote-posts, prevent duplicate strikes, cache bounded classifier results by post identifier, apply the user's settings, and show the local activity log. On supported Chrome devices, classification uses Chrome's on-device Gemini Nano model.

## No transmission or sale

VagueBlock does not send tweet content, account handles, activity records, browser history, or credentials to the developer or to third parties. It does not use analytics, advertising, tracking pixels, remote model APIs, or data brokers. It does not sell or share user data.

## Retention and control

Extension data remains in Chrome extension storage until the user deletes it, resets VagueBlock, or removes the extension. Users can export or delete local extension data from VagueBlock's options page.

## Security

VagueBlock uses Chrome extension storage and requests only the permissions needed for its x.com functionality. It does not request access to passwords, payment information, downloads, or browsing history.

## Changes

If this policy changes, the updated version will be posted with a new effective date. Changes that alter data handling will be reflected accurately in the Chrome Web Store Privacy tab before release.
